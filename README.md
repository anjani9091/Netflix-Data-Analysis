 # Netflix Data Analysis Using Python

## Project Overview
Exploratory Data Analysis (EDA) of Netflix movies and TV shows to understand content distribution, ratings, genres, countries, and catalog trends.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Google Colab
- Git and GitHub

## Project Workflow
1. Loaded and inspected the Netflix dataset.
2. Checked missing values and duplicate records.
3. Cleaned data and handled missing values.
4. Analyzed movies and TV shows.
5. Explored ratings, genres, countries, and release trends.
6. Created visualizations to communicate findings.

## Key Findings
- Movies make up approximately 69.6% of titles in the commonly used Netflix titles dataset.
- TV shows make up approximately 30.4%.
- Rating, country, and genre analysis helps reveal patterns in Netflix's catalog.
- Data cleaning improves the reliability of the analysis.

## Project Files
- `Netflix_Data_Analysis.ipynb` — Jupyter notebook containing the analysis and code.

## Skills Demonstrated
Python, Pandas, NumPy, Data Cleaning, Exploratory Data Analysis, Data Visualization, Matplotlib, Seaborn.
